# AI Usage Declaration

This project, the **Vedic Gemstone Recommendation App (Navaratna)**, was developed with the assistance of artificial intelligence.

## Details of AI Assistance

- **AI Model**: Gemini 3.5 Flash (High) (developed by Google DeepMind)
- **Role**: AI Pair Programmer / Assistant
- **Contributions**:
  - **Planning & Design**: Helped outline the application architecture, design system, and astrological recommendation flow.
  - **Separation of Concerns**: Helped migrate the monolithic single-file client-side architecture to a structured Node.js Express server backend and decoupled JSON database model.
  - **Aesthetics & Styling**: Designed the cosmic dark theme, layout structures (grids and flexboxes), glassmorphism styles, and glowing animations for the gemstones.
  - **Content Curation**: Assessed and summarized traditional Vedic astrology connections (ruling planets, mantras, fingers, metals) and compiled the mythological origin lore of the Navaratnas.
  - **Code Implementation**: Generated the codebase including `package.json`, `server.js`, `routes/api.js`, `data/gemstones.json`, and frontend files `public/index.html`, `public/style.css`, and `public/app.js`.
  - **Documentation**: Aided in drafting `PROJECT_NOTES.md` and this usage declaration.

## Human Oversight

All AI-generated code, API endpoints, JSON configurations, CSS styles, and recommendation rules were reviewed, refined, and validated by the developer to ensure accuracy, safety, code quality, and performance.
